Configuration Backup

Signed Updates

Release manifests require a trusted Ed25519 signature and packages require the signed SHA-256 checksum.

Loading update channel…

Administrators configure the release channel with KITSUNE_UPDATE_MANIFEST_URL and KITSUNE_UPDATE_PUBLIC_KEY. Server mode downloads a verified package but leaves installation to the administrator.

Support Report

Collect diagnostics, installed versions, recent log tails and project metadata while redacting credentials and personal filesystem paths.

The report is saved with a SHA-256 checksum and also downloaded through the current interface.
