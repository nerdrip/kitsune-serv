# Assets

- `icon-source.png` — generated source artwork on a chroma-key background.
- `icon.png` — transparent 512×512 application and Linux icon.
- `icon-256.png` — transparent 256×256 Windows-friendly PNG.
- `icon.ico` — Windows icon containing 16, 24, 32, 48, 64, 128 and 256 px layers.

Run `powershell -File scripts/build-icon.ps1` after replacing `icon.png` to rebuild `icon.ico`.
